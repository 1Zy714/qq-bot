>

## 卡住时的处理

| 症状 | 先查 |
|---|---|
| 工具没被调用 | 工具名/描述是否清楚；模型是否支持 function calling |
| 回复变慢 | 是否有人在 system 里塞了动态内容（缓存失效） |
| 检索不命中 | 关键词是否太短；时间衰减是否把老数据权重压太低 |
| 记忆写不进去 | 是否被合并规则判成重复；是否超过限流 |
| 游戏动作不生效 | 门控是否跳过；动作后有没有核验 |
