# 本地模型 DSH 实例（2026-10-26）

> 目的：一个**只走本地模型**的 DSH，和主实例（3080，DeepSeek 远程）并行，互不干扰。

## 一句话

```bash
# 1) Windows 侧起 Strata（8080）
/mnt/c/Windows/System32/cmd.exe /c start "" /min "Y:\Strata\.venv\Scripts\python.exe" \
  "Y:\Strata\serve\server.py" --engine strata --config "Y:\Strata\strata-iq2_xs.json" --port 8080

# 2) WSL 侧起本地 DSH（3081）
cd ~/project/deepseek-harness
LOCAL_LLM_KEY=sk-local pnpm dsh --profile local --no-open --port 3081
```

启动日志会打印带 token 的地址：`http://127.0.0.1:3081/?token=<每次重启都不同>`

## profile：`~/.dsh/profiles/local`

- 用 `pnpm dsh --profile local --from-default-profile web --dump-config` 从 web 模板生成
- 只装了 `@deepseek-ai/dsh-base` + `dsh-web-app`（**没有** maid / mnemon / market 这些）
- 唯一的自定义在 `cordis.patch.yml`：
  - `llm-pi-ai` 增加 `local-qwen` provider → `http://127.0.0.1:8080/v1`
  - `agent-default-model` 钉死到 `local-qwen / qwen3.8-flash-next-iq2_xs`

## 三个坑

1. **`--profile <name>` 后面不能再写 `web`**：`dsh --profile local web` 会报
   `too many arguments ... got 1: web`。profile 自己决定跑哪个 app。
2. **本地模型先出 thinking**：`max_tokens` 太小会只返回 reasoning、`content` 是 null
   （实测 20 tokens 时正好被思考吃光）。profile 里给了 `maxTokens: 8192`。
3. **`apiKeyEnv` 必须解析到非空值**：启动前 `LOCAL_LLM_KEY=sk-local`，
   否则适配器起不来（本地服务自己不校验 key）。

## 停 / 重启

```bash
# 停 DSH（3081）
pkill -f 'dsh --profile local'

# 停 Strata（Windows 侧）
/mnt/c/Windows/System32/cmd.exe /c "for /f \"tokens=5\" %a in ('netstat -ano ^| findstr :8080') do taskkill /F /T /PID %a"
```
